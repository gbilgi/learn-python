# Glossary

**Integer**  
A numeric value without a decimal, e.g., 10

**Float** 
A numeric value with a decimal, e.g., 10.0

**String**  
A sequence of characters enclosed in quotes.

**Boolean**  
A data type representing True or False.

**None**  
A special data type in Python denoting no value, NoneType.

**Variable**  
A label that points to a memory location storing data.

**`print()`**  
A function to output text to the console in Python.

**Concatination**  
Joining strings together using the + operator.

**Comment**  
Non-executable text in the code, marked by #

**`input()`**  
A function to take user input as a string in Python.

**Case Sensitive**  
Python's distinction between uppercase and lowercase letters.

**Typecasting**  
Converting a variable from one data type to another.

**Boolean Casting**  
For empty strings or 0, returns False; else True

**Integer to Boolean**  
0 converts to False, others to True

**String to Boolean**  
Empty string converts to False, non-empty to True

**Float to Integer**  
Rounds towards zero, e.g., 3.99 becomes 3

**Arithmetic Operators**  
Include +, -, *, /, %, //, and **

**Comparison Operators**  
==, !=, <, >, <=, >= used for comparisons.

**Logical Operators**  
Combine conditions, include and, or, not

**Assignment Operator**
Assigns values, denoted by =

**Control Statements**  
Decide execution flow, like if, else, elif

**Nested if**  
An if inside another if, creating multiple layers.

**Loops**  
Structures that repeat a block of code while a condition is true.

**DRY Priciple** 
Don't Repeat Yourself - avoid code repetition.

**While Loop**  
Runs code block while a given condition is true.

**Infinite Loop**  
A loop that runs endlessly because its terminating condition is never met.

**Iterable**  
An iterable is a collection of items (the playlist). It holds data (list, string, range).

**Iterator**  
An iterator is what walks through an iterable. It walks through it one step at a time.

**Break Statement**  
Stops loop execution and exits the loop immediately.

**Continue Statement**  
Skips the current iteration in a loop and moves to the next one.

**`range()` Function**  
Generates a sequence of numbers from start to end-1 with a step.

**For Loop**  
Iterates over items in a sequence, like a range of numbers.

**Nested loops**  
For every ONE step of the outer loop, the inner loop runs to completion  .
A loop inside another loop, used for complex patterns or iterations.

**Prime Number**  
A number greater than 1, only divisible by 1 and itself.

**Scraper**  
Operation to get the last digit of a number using modulus 10

**Scissors**  
Operation to remove the last digit of a number using integer division by 10
