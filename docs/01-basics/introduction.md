### Overview
Python is an open-source easy to learn general purpose programming language.  
It was developed by **Guido Van Rossum** in 1993.

Written in plain english, It is easy to code and improves productivity. It has a vast library support.

Python can be used almost anywhere and offers lots of career options.

### Key features of Python
1. Readable syntax: Uses indentation and English like key-words. Fewer lines of code.
2. Multi-paradigm: Supports **procedural**, **object-oriented** and **functional** programming style.
3. Interpreted & interactive: Code runs line-by-line at run-time (no compilation step).
4. Cross-platform: Runs on Windows, Linux, MAC, Raspberry Pi.
5. Huge ecosystem: Thousands of third-party libraries and large standard libraries.
6. Free and open source: No license cost. Freely modifiable and redistributable.

### Related
**Library:** Is a pre-written code that can be called at any point of time.

**Interpreter:** The Python interpreter is a program that reads the Python code and executes it line by line. It's a powerful tool for running Python code interactively, we can type a command and see the result immediately.
