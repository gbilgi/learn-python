# Learn Python

My personal notes, code, and projects while learning Python, published as a searchable website.

**Website:** https://gbilgi.github.io/learn-python/

## Goal
Learn Python well enough to automate real tasks, with every topic documented in my own words and backed by runnable code.

## Roadmap
- [ ] 1. Basics: installation, syntax, variables, data types
- [ ] 2. Core Syntax: print function, operators, control flow, loops
- [ ] 3. Data Structures: strings, lists, tuples, dictionaries, sets
- [ ] 4. Functions & OOP: defining functions, parameters, lambda, scope, classes, objects
- [ ] 5. Practical Skills: file handling, error and exception handling

## Repository layout
- `docs/` explanations (published as the website)
- `code/` runnable scripts that mirror `docs/`
- `projects/` mini projects that apply what I learn
- `notebooks/` Jupyter experiments

## Working on it locally
Activate the `docs` conda environment, run `mkdocs serve`, and open http://127.0.0.1:8000.
